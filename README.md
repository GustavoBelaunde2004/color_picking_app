# Favorite Color App

This is a simple full-stack web app that lets users submit their name and favorite color. If a user has submitted their info before, the app looks it up and gives them the option to update it.

It's built with:

- Express.js for the backend
- Pug as the template engine
- MongoDB for the database
- JavaScript + Fetch (AJAX) frontend

---

## Features

- Submit a name and favorite color
- If the name already exists:
  - Shows the previously saved color
  - Asks if you want to update it
- View favorite colors for all users using a dropdown
- All interactions happen without refreshing the page
- Messages can be dismissed with a close button
